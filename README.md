# Roblox Asset Explorer

An open-source, unofficial Roblox asset lookup website. [MIT licensed](LICENSE).

## Features
- Search by Roblox asset ID or catalog/library/bundle URL
- Preview public asset thumbnails when the Roblox thumbnails API permits browser access
- Open catalog, library, and bundle pages
- Responsive dark UI, no accounts required

## Limitations
This first release does not yet provide raw asset downloads, clothing template extraction, audio playback, model rendering, or animation playback. Roblox API CORS restrictions can prevent thumbnails from appearing. Private or restricted assets are not bypassed.

## Local use
Open `index.html` in a browser or serve the folder with `python -m http.server 8000`.
